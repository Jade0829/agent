## Evidence

- Verify before you claim. State what was run and what was not; if a check
  failed or was skipped, say so with the output.
- Before creating an issue or starting an implementation from an analysis
  document, search for existing issues and merge/pull requests first. A status
  line in a document describes the day it was written, not today.
- Check product facts against the remote base branch (`origin/<base>`), not
  against whatever topic branch happens to be checked out locally.
- When reviewing a merge/pull request, read files at the request's head commit,
  never from a local checkout that may be older or newer.
